- DSD playback: DSF and uncompressed DSDIFF/DFF via a custom Media3 extractor and a bundled DSD-to-PCM engine (88.2 kHz / 16-bit output).
- Library, albums, artists, user and smart playlists, favorites, and play counts that only count tracks you actually heard.
- Mini player and full player with queue, repeat/shuffle, and custom cover art.
- Faster scrolling: bounded in-memory and on-disk cover caches, cached track metadata.
- Selectable accent colors and library size/duration filters.

**APK notes:** arm64-v8a only, minimum Android 9 (API 28). This is a **debug-signed** build, not a Play Store release. Android may ask you to allow installing from unknown sources. DST-compressed DSDIFF is not supported.
