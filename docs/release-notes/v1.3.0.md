- DSD files show up like any other track: real title, artist, album and cover from their tags, the true duration, and the exact bit rate with the DSD rate (DSD64/128/256).
- "Open with": FeatherW8 is offered for audio files and for `.dsf` / `.dff` / `.dsd` in file managers, and plays what you opened.
- Faster: this is now an optimised (R8) release build instead of the debug build, and switching between Library and Playlists no longer stutters when you tap quickly.
- DSD tracks no longer disappear from Library when a minimum-duration filter is set.
- Updates now install over each other: the APK is signed with the project's own key. **This one is the exception** - uninstall the older debug-signed build first (its favorites, playlists and play counts are not carried over).

**APK notes:** arm64-v8a only, minimum Android 9 (API 28). Not distributed through Google Play, so Android may ask you to allow installs from the app you opened the file with. DST-compressed DSDIFF is not supported.
