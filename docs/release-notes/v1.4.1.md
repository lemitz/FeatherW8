- The play counter is now reliable on phones that slow an app down while the screen is off (Nothing OS in particular). It used to give up on any stretch where the app was not polled for more than 1.5 seconds, so a track listened to with the screen off could play to the end and still never be counted. Listening is now measured from the player's position when it pauses, is seeked or ends, no matter how often the app was woken up in between.
- The player now holds a wake lock while playing, so the screen-off case stays steady in the first place.
- Files whose length the player cannot work out (VBR MP3 without a length header, for example) are counted too; the length found in the library is used for them.

**APK notes:** signed with the same project key as before, so it installs over the previous version and keeps your data. arm64-v8a only, minimum Android 9 (API 28).
